## Honest caveats on this capture (per Codex review 2026-07-17, findings 2/5/11)

- **The queries are analyst-crafted and definition-*informed*, not definition-*only*.** They deliberately avoid each sub-field's identifying/opaque term (no "hyper-responder", "ApoB"/"apolipoprotein", "isocaloric"/"leave-one-out"/"energy-partition"), but they DO contain general topical words absent from the hand-written constrained definitions (e.g. "dietary cholesterol", "lipoprotein particles", "cardiovascular"). So this demonstrates that a plain-language description *avoiding the sub-field's own local term* still routes to that sub-literature — NOT that a purely definition-token query does. Attributing the routing to the constrained definition alone would overstate it.
- **The searcher (orchestrator) knew the target literatures**, so informed query-crafting is not separated from definition-mediation. This is an illustration of routing, not a controlled result.
- **T4 (transparent control "dietary cholesterol") was not run as a separate definition-mediated query.** The only control observation is that Q-naive already surfaces dietary-cholesterol material (Mayo, the 186 mg fact), so the transparent term needs no routing — consistent with the expected null, but not a controlled isolation of the effect.
