# Novelty position — the recall extender

- **The claim, in the field's vocabulary (no project-local terms):** a pay-as-you-go, schema-last system for onomasiological cross-domain concept search, in which automatic term recognition (including novel-sense detection for common words) triggers on-demand definition generation in a controlled defining vocabulary, and the generated gloss — not the term — serves as the retrieval representation for cross-community concept matching with thesaurus-style typed relations (equivalent / broader / narrower / related), with no agreement-first, hand-curated source-of-truth ontology ever constructed. **Amended 2026-07-17 (user decision):** the design permits — and now includes — an optional **decentralized, git/torrent-like commons**: an append-only, fork-able registry of generated definitions and verified typed mappings with provenance, in which every shared artifact is a *derived, regenerable cache* (re-derivable from source texts by the same pipeline) and **no canonical merge ever occurs** (forks coexist; disagreement is expressed as typed links between entries). What remains forbidden is the graveyard's property set: agreement-required, hand-curated, expensive-to-regenerate canonical resources. Stance ancestors for the decentralized-commons form: emergent semantics (Aberer 2004), PDMS — the claimed delta is unchanged (LLM-generated definitions as the matching substrate + regenerable-cache economics). **Shared-resource distinction (Codex finding 5):** the design DOES permit one shared artifact — a *fixed, small, domain-generic defining word list* (the LDOCE-style controlled defining vocabulary: static, maintenance-free, never domain-specific); what it forbids is any shared *domain concept resource* (ontology, termbase, glossary) — the artifact class whose acquisition/maintenance economics the diagnosis says killed every predecessor. Static generic word lists survived for decades precisely because they need no curation; that asymmetry is part of the argument, not a loophole.
- **Fields it plausibly lives in:** ontology matching / semantic-web data integration · terminology science (ATE/neonymy, terminography) · computational lexicography (definition modeling, defining vocabularies, gloss-based WSD/retrieval) · IR (query expansion, reverse dictionary).
