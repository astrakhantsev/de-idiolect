# Recall-lift backtest on the project's own reinvention failures

## 1. The idea, and why it is the strongest instrument available

We cannot measure absolute recall (that needs the full relevant set, which is unknowable). But we do not need to. We need a **differential**: cases where a recall-extended query surfaces prior art that a plain idiolect query misses. And the project has a rare asset for exactly this — **three documented failures where a search in the project's own vocabulary returned a *confident null* that later turned out to be wrong** (`novelty-protocol.md` §receipts):

| episode | project searched for | result | overturned by |
|---|---|---|---|
| 2026-06-29 | the full target, 9-agent fan-out | "no prior art found" | later refuters |
| 2026-07-13 | `m*` novelty | "novel" | Clemen & Winkler 1985 (~5 min) |
| 2026-07-16 | the replacement direction | "novel" | Bröcker 2008 (foreclosed) |

This is the thing the eggs demo and the 07-16 weights-only experiment both lack. In eggs, "the naive query misses the sub-literature" is the **orchestrator's assertion**. In the reinvention cases, "the idiolect search returned a confident null" is a **measured historical fact**. That converts the experiment from a routing illustration into a scored recall-lift measurement with objective, pre-registerable endpoints: *does the known prior-art source appear in the hit list — yes or no?*

There is even an external calibration point. Larsen & Bong 2016 (primary-verified, `novelty-protocol.md`) measured this exact failure — motivated PhD students searching for a **renamed** construct — at **9% / 3% recall**. Our plain-arm null rate should sit near that floor; the recall-extended arm's lift over it is the number the FLF entry is missing.

## 2. The two traps the design must clear

**Trap 1 — circularity (the user's "reconstruct from known cross-domain terms" path, if taken literally).** If the recall-extended query is built from the *known* field term ("effective sample size", "value of information"), then of course it finds the prior art — that only proves "if you already know the answer you can find it", which is the confound the eggs demo already carries. The non-circular version builds the query from a **blind, domain-stripped operational definition that never contains the answer term**. We do not need to reconstruct anything: those definitions **already exist, frozen and hashed**, from the 07-16 experiment (definitions `001bb8d7…`, generated by a context-free model, grep-clean against the answer key). The only new step is running *search* on them (07-16 was weights-only) and scoring the hit list.

**Trap 2 — the answer keys are not all sound.** The 07-16 experiment already found that only one of the four keys is clean; the others are contaminated, mis-mapped, or transparent. Backtesting them as if all four were clean reinventions would launder the same overclaim the 07-16 review caught. The honest move is to let the case-by-case *spectrum* be the finding (§3), not to average it into one recall number.

## 3. Case triage — the spectrum IS the result

| case (coinage) | claimed owner | key status | expected behaviour | what it proves |
|---|---|---|---|---|
| **C2 "operating requirement" (cold-start)** | value of information / preposterior — Raiffa & Schlaifer 1961 | **CLEAN** (the one cell that separated 07-16: blind def → R&S L3-exact ×2; raw coinage → L0, steered to requirements-engineering / accounting) | plain arm misses / steers wrong; recall-extended arm reaches VoI | the **clean recall lift** — the headline case |
| **C4 "read the enumerations, not the votes"** | set-union multiple-classifier combination — Ho, Hull & Srihari 1994 (TPAMI, **primary-verified**) | **CLEAN but different**: the blind pipeline already found this owner that *three human-audited passes missed* | plain arm misses; recall-extended arm reaches multiple-classifier-combination lit → Ho 1994 | **reproduce a documented win via actual search** (07-16 got it weights-only) |
| **C1 `m*` (per-question critical count)** | "effective sample size" — Clemen & Winkler 1985 | **CONTAMINATED**: the blind def is a *tipping-point multiplier* λ\* = (logit t − logit π₀)/D̄, **not** an effective count; 07-16 draws named weight-of-evidence (Good/Turing), reverse-Bayes/critical-prior (Matthews), extremization (Baron/Satopää) instead. C&W is likely a **mis-map** | ambiguous — depends which target you pre-register | **the tool corrected our own answer key**: the "reinvention of effective sample size" may never have been one. A finding, but not a lift datum until the true owner is fixed |
| **C3 "the signal, not the cut, is the bottleneck"** | sufficiency / proper-score decomposition — Bröcker 2008 (foreclosure) | **TRANSPARENT slogan**: 07-16 control reached Murphy 1973 & Blackwell from the *slogan alone* | plain arm ALREADY partly succeeds → low lift; **but Bröcker specifically was missed by every arm** | the **tool's LIMIT**: transparent slogans don't need it, and the exact keystone (Bröcker) is reachable only by citation-walk, not keyword — on-message honesty for an entry about search failure |

The C2→C4→C1→C3 spectrum operationalizes the opacity gradient the 07-16 experiment could only hypothesize (§7.3-i): **the definition layer's value is inversely proportional to the coinage's transparency.** That is a cleaner, more defensible contribution than a single averaged recall number would be.

## 4. The three FLF cases are NOT interchangeable — only one carries a documented miss

The user relaxed the case set to "eggs / collider / COVID, any of the three FLF cases." But the experiment's entire strength is the *documented miss*, and the three cases differ exactly on that axis. Evidence-strength hierarchy, strongest first:

1. **Our own reinvention receipts (m\*, judge-dependence) — STRONGEST.** *We* measured the confident null; *we* later found the prior art. Ground truth on both sides, self-measured (§1 table).
2. **COVID droplet-vs-aerosol — STRONG, and the one FLF case worth using.** A genuine, famous, *externally documented* cross-domain miss: the infection-control idiolect ("droplets"; the mis-remembered ~5 µm droplet/aerosol threshold) kept the owning **aerosol-physics** literature — Wells 1934's evaporation-falling curve, Wells–Riley — invisible from a medical-idiolect search for ~60 years, until the 2021 reckoning (Randall, Marr, Jimenez; the "5-micron error" reconstruction). The owner sits in a *different field under a different word*, which is precisely the recall-extender's target structure. The miss is real and checkable; the new work is reconstructing "plain infection-control query fails / definition-mediated aerosol-physics query reaches Wells" and scoring it. **⚠ Verify first** (same primary-read gate as every other case): confirm the 5 µm-error reconstruction and Wells 1934's ownership against primary text before this leg is load-bearing. (Note: COVID was earlier excluded by user instruction; this 2026-07-17 message relaxes that.)
3. **Eggs and collider — ROUTING-ONLY, no documented miss.** In both, "the naive query misses the owner" is the demo-writer's assertion, not a historical fact. Eggs is already built (`2026-07-17-eggs-routing-microdemo.md`); a collider version would be the same shape. The **collider** additionally mismatches the theory: the LHC case (`2026-07-16-flf-application-criteria-first.md` §3) is about probing *dependence* among apparently-independent safety arguments (Hawking radiation · cosmic-ray bounds · white-dwarf survival) — that is the **dependence-proxy** theory, unsearched and unbuilt, not the recall-extender. Keep eggs/collider as optional routing color; do not let them dilute the ground-truthed leg.

**Net:** the strongest package is **two project reinventions (C2 clean-lift + C4 reproduce-win) + COVID aerosol (external famous miss)** — three ground-truthed cases, one of them an FLF case. Eggs stays as the already-built routing companion; collider is skippable for this theory.

## 5. Concrete design (pre-registered, non-circular)

Two arms per case, **both search-enabled** (this is the delta from 07-16), both blind (reads-blocked, no answer key in context), each fed a single frozen input, hit list captured verbatim:

- **Arm P (plain / idiolect):** input = the frozen K-arm gloss (e.g. *"the operating requirement — the cold-start operating requirement for the audit unit"*). Task: *what is this called, which fields own it, oldest treatments with citations* — and **actually search**.
- **Arm R (recall-extended):** input = the frozen blind D-arm definition (domain-stripped, answer-term-free, hashed 07-16). Same task, same search budget.

**Scoring (objective, per case, against pre-registered targets):**
- L1 = right field/community named · L2 = canonical field term · L3 = the exact source (author + year, verified by **opening the primary** per `feedback_verify_citations_primary_text` — a hit list string is a candidate, not a confirmation).
- **Validity gate (per case):** Arm P must *reproduce the historical null* (fresh idiolect search still fails to reach the target). If Arm P now finds it, the historical null was a fluke and that case is **void** — report it, don't count it.
- **Recall lift (per case):** target level reached by Arm R that Arm P does not reach, on a live (non-void) case.

**Pre-registered targets** (freeze before any run): C2 → Raiffa & Schlaifer 1961 / "value of information" / EVPI-EVSI. C4 → Ho, Hull & Srihari 1994 / "class set combination" / union-of-candidate-sets. C1 → **held** (open-target variant only: does R reach a coherent owner family P misses?). C3 → Bröcker 2008 arXiv:0806.0813 **and** the softer {Murphy 1973, Blackwell, sufficiency} set, scored separately (the split is the point).

**Controls carried from 07-16:** same-family caveat (N Claude draws ≈ shared corpus, not independent confirmation — 2 cross-model draws is a floor); every claimed hit verified against primary text; fabrication count logged; a too-perfect snippet treated as a fabrication signal (`novelty-protocol.md` §8). Blindness enforced at the **tool** level (deny Read/Glob/Grep, neutral cwd) per `feedback_blind_pass_tool_level`, not by prompt wording.

**Honest scope (state it in the entry, unbudged):** this measures ONE link — *does a blind definition-derived search query retrieve the true owner where the idiolect query does not* — on the project's own history, n≤4, one project, Claude-family draws. It is not end-to-end (coinage detection is not wired in; the definition-generation quality is only partly under test since the defs are frozen). Same honesty bar as the bge-large prototype.

## 6. What to run given the 07-19 deadline, and expected payoff

Minimum viable, highest-signal run: **C2 (clean lift) + C4 (reproduce-a-real-win via search)**, two arms each, 2 cross-model draws, ~half a day at Claude-Code pace (the frozen inputs and hashes already exist; the new work is the search runs + primary-verified scoring). Add **C3 as the declared limit** (cheap — reuses the same slogan input) and **hold C1** with a one-line note that the tool corrected our own key.

If an FLF-case leg is wanted (responsiveness + a third ground-truthed case): add **COVID droplet-vs-aerosol** — verify the 5 µm-error reconstruction and Wells 1934 ownership first, then reconstruct Arm P (infection-control idiolect: *"droplet transmission respiratory precautions distance"*) vs Arm R (aerosol-physics definition: *"small suspended particles carrying pathogen staying airborne, settling time by particle diameter"*) and score whether Arm R reaches the aerosol-physics owner that Arm P misses. **Skip eggs/collider** for the measured run (eggs already exists as routing color; collider is the wrong theory).

Payoff for the entry: it upgrades the measured leg from *"one embedding link on eggs, confirms a near-obvious routing effect"* to *"measured recall lift on the project's own documented reinvention failures, scored against ground truth, anchored to Larsen & Bong's 9%/3% benchmark, with the tool's limit (transparent slogans, citation-walk-only keystones) reported honestly."* That is a **measured, mildly surprising finding on real failures** — the axis the FLF brief says is the only path above stepping-stone tier — and it demonstrates the idiolect-trap discipline working on the project's own history, which is the reframe-to-method lever the session synthesis identified.

**Risk to price honestly:** the 07-16 weights-only result was lukewarm (2/4, clean only on C2). Search could genuinely help (it is the tool's real modality and can reach beyond weights) or could just reproduce the opaque/transparent split. **Both outcomes are publishable** — a clean 2-case lift strengthens the entry; a "lift only on opaque coinages, keystone reachable only by citation-walk" result is an honest limit that is itself on-message. The **only** worthless outcome is the circular one (Trap 1): building Arm R's query from the known field term. The design above forecloses it by construction.
