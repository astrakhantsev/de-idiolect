# de-idiolect

Code and receipts for **"The vocabulary seam: why cross-community knowledge doesn't compound, and a lazy way to bridge it"** — an FLF Epistemic Case Study Competition entry. *De-idiolect* (verb): produce a description of a concept with the community's local vocabulary removed, and use that — not the term — as the retrieval key.

**Status: draft package.** The interactive architecture diagram is pending realignment.

**Where to start:** [`READING-GUIDE.md`](READING-GUIDE.md) maps a limited reading budget across the whole package — a ~10-page core (abstract → §1 → §2 → §5.5 → §7), then supporting material and appendices. *(Post-submission, navigational only.)*

- **2026-07-20 — `hook/term-scan.sh`: scan mode for the coin-time hook.** For a project with *no glossary yet* — where neither the manual check nor the glossary-watch hook has anything to fire on — point the scanner at the prose and one isolated model call surfaces the project's most local coinages; a **mandatory curation step** gates which ones proceed; the unmodified `term-check.sh` then checks the kept terms into a `GLOSSARY-SEED.md` whose entries match the glossary-watch regex (scan → seed → watch). Includes a committed self-application on this repo's own prose (`hook/example-scan/`) scored against `GLOSSARY.md` §A, with the detection prompt, per-draw isolation manifests, instrumentation, and a contamination check. Detection is heuristic — a *different* detector from the prototype's, and not a claim to fix its record. The prototype uses **keyness** (a deterministic frequency-contrast statistic: how over-represented a word is here versus a reference corpus) — the right choice for a frozen, offline measurement in which detection is not on the measured path anyway (the evaluated concepts are hand-supplied), and where the honest finding is that "raw keyness under-delivers." Scan instead asks a *model* which terms an outside expert would not recognize as established vocabulary — a different signal (keyness surfaces whatever is distinctive by frequency, including ordinary domain terms, and misses rare coinages; the model judges established-ness directly), fit for a *live* convenience where nondeterminism is acceptable because the curation gate absorbs it. It is unmeasured on the prototype's retrospective detection endpoint, so surfacing coinages here says nothing about that record. The per-term check is the product. See `hook/README.md`.
