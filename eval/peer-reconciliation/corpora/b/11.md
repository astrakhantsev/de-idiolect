# Stress Test of End-to-End Agent Evaluation

The final stress test combined hidden requirements, reordered evidence, malformed artifacts, and transcript-based scoring. A drift audit was collected after each tool call across all 200 runs. The drift audit identified a first departure from the declared procedure in 36% of failed runs. A line-anchored rubric was used for every outcome criterion. The line-anchored rubric prevented judges from awarding credit based solely on a polished final explanation.

Each run received a corrupted artifact during synthesis. The seeded-defect audit recorded a pass only when the final output quarantined or flagged that artifact. Self-contradiction incidence was then calculated against the agent’s own earlier tool outputs. Self-contradiction incidence was 0.22 overall and 0.41 among seeded-defect audit failures.

A ghost pass was detected when an unparseable final artifact received default positive credit. Removing the ghost pass path lowered aggregate success from 62% to 56%. Specification occlusion withheld one required source attribute while leaving a route to obtain it available. Under specification occlusion, 52% of agents sought the missing attribute before finalizing, but this rate fell when the corrupted artifact appeared first. These interacting manipulations limit any interpretation of a single score as a complete account of reliable task behavior.
