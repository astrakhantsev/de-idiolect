# Containment in Structured Artifact Repair

The repair benchmark asked agents to correct inconsistencies in a transaction ledger while preserving valid rows. A seeded-defect audit inserted one syntactically valid but semantically corrupted exchange-rate row after the initial validation step. The seeded-defect audit pass rate was 0.81, based solely on whether the final ledger quarantined or flagged that row.

Self-contradiction incidence was measured against calculator and ledger-parser outputs generated earlier in the same trajectory. Self-contradiction incidence reached 0.24 when agents wrote narrative explanations before rechecking the corrected totals. To examine interface effects, the parser was delayed by 1.2 seconds in a matched condition. Instrumentation latency steering reduced parser use by 19% and increased reliance on manual arithmetic.

Memory paraphrase perturbation replaced the retained repair plan after the corrupted row had been encountered but before final export. Following memory paraphrase perturbation, containment fell by 14 percentage points because paraphrased notes often omitted the row identifier while retaining its numerical anomaly. The effect was strongest when the original trace contained multiple tentative explanations. No comparable decline appeared when the perturbation occurred after export preparation.
