# Interface Perturbations in Retrieval-and-Export Runs

Agents retrieved technical records, selected supporting fields, and exported a structured answer. Instrumentation latency steering was induced by delaying one high-coverage retrieval tool after its first successful result. Instrumentation latency steering reduced its later selection rate from 0.46 to 0.27. Memory paraphrase perturbation replaced working notes immediately before field selection. Under memory paraphrase perturbation, export accuracy declined by 13 percentage points despite unchanged retrieval evidence.

Equivalent tool results were randomized among repetitions. Permutation sensitivity collapse lowered exact export success from 64% to 41%, with the largest losses among agents that committed to the first presented schema. A ghost pass was observed when malformed exports bypassed the grader’s schema parser. The ghost pass rate was 0.09 in the original configuration and zero after explicit parser-failure handling.

Specification occlusion withheld a required unit convention from the initial task materials. With specification occlusion, successful agents queried the documentation tool before normalizing values, whereas unsuccessful agents assumed a default unit. The interaction between delays and withheld information was substantial: agents facing both conditions sought documentation less often than agents facing specification occlusion alone. Thus, measured information-seeking behavior was sensitive to the evaluation interface as well as the available evidence.
