2. **τ definitions (exact).** All three share v0.8's per-level counting (k/c/u after quote validation), fails rule (c ≥ 2 ∨ k/(k+c) ≤ 0.3), abstain rule (k+c < 2), terminals (§4), composition table (§5), and endpoints formulas (§6).
   - **τ0** = v0.8 verbatim: covers iff k ≥ 2 ∧ c = 0; L = max covers level; retrieval query = L2.
   - **τ1** = τ0 + **evidence-exhausted promotion**: the direction's effective level L† extends its covers base upward through CONSECUTIVE SILENT levels — k+c < 2 **∧ c = 0** (fold R10, self-caught pre-build: a level holding a single valid contradiction is abstain under the frozen aggregation but is NOT evidence-exhausted, and promoting over it would contradict the rule's own rationale; every measured promotion is k0c0, so the §1 basis is unchanged) — above it; a level with c ≥ 1 or agg ∈ {mixed, fails} stops the extension; a direction with no covers level at all (L = −1) never promotes. Disclosed residual: exactMatch (2,2) tolerates ONE direction with a genus-only promoted base when the partner direction's base is ≥ L1 (this is what recovers P02); tightening that too would foreclose the measured basis and is left to a future version if TEST shows it leaking. Also at τ1+: **retrieval query = the concatenation L0 + " " + L1** (single space, that order); every other retrieval rule (§2.6/§9-F7: mutual@3, (−sim, index) ranking, snapshot pinning, hit definition) unchanged.
   - **τ2** = τ1 + **one-dissent covers**: covers iff k ≥ 2 ∧ c ≤ 1. Disjointness with fails is structural: c ≤ 1 excludes c ≥ 2, and k ≥ 2 ∧ c ≤ 1 forces k/(k+c) ≥ 2/3 > 0.3, so no level can be both covers and fails.

Human dispositions are recorded by `review_pairs.py decide <pair> confirm|override:<relation>|defer [--notes …]`, appending {pair, terms, active τ, exact verdict shown, decision, notes, UTC timestamp} to `runs/review/decisions.jsonl` (fold R6); dispositions DO NOT enter E1/E1b/E1c — the endpoints measure the automatic pipeline only, and an offline test asserts the scoring code references neither the setting nor the decisions file.
