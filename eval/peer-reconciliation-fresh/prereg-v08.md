## 2. Pipeline (frozen; models fixed as stated)

1. **Excerpts** (mechanical): sentence split; window = preceding + match + following sentence, where a neighbor sentence containing another same-side coined term is dropped; in every prompt the target term is masked ⟦TERM⟧ (⟦T1⟧/⟦T2⟧ in two-side prompts) and every other same-side coined term ⟦X⟧. Verification sample per term = first 6 pool excerpts in (doc, position) order (pool = all 11 docs, §1); fewer than 4 → terminal per §4.
2. **Checklists**: per term, one isolated sonnet call (`prompts/checklist-extract.md`) from the masked pool bundle; leak-checked.
3. **Ladder definitions**: per term, one isolated call (side a: opus; side b: codex gpt-5.6-terra) with `prompts/gen-definition-v07.md` → JSON {"L0","L1","L2"} cumulative (L0 genus one sentence; L1 + mechanism; L2 + measurement/conditions, all checklist commitments); leak-checked.
4. **Ladder conformance gate (new)**: (a) mechanical — parseable JSON, three non-empty levels, word counts w(L0) < w(L1) < w(L2), w(L0) ≤ 45; (b) semantic — one isolated sonnet call per side (`prompts/ladder-conformance.md`, batched) judging per term: L1 preserves L0's content; L2 preserves L1's; L1 states the checklist's mechanism commitment(s); L2 states every checklist commitment — verdict conformant | nonconformant(+reason). Failures route through the §1 artifact gate state machine (one regeneration total, then configFail).
5. **Polarity gate**: batched per side (a judged by codex terra, b by opus) on L2 only; inverted → **configFail** for the affected pairs.
6. **Retrieval**: BAAI/bge-large-en-v1.5 from the local HF snapshot (snapshot directory hash recorded in the freeze manifest); inputs = full document file text and full L2 text, model-default tokenization and truncation (512 tokens), `normalize_embeddings=True`; similarity = dot product of normalized embeddings (cosine); ranking by descending similarity with ties broken by lower document index (stable argsort); query = each side's L2 against the OTHER side's full 11-doc corpus; hit iff ≥1 of top-3 docs contains the partner term string (case-insensitive substring); mutual = both directions hit. Retrieval executes locally and deterministically; an execution failure is an infrastructure fault of the RUN (fix and re-execute this stage; it is not a per-pair verdict).
7. **Matrix verification**: one isolated call per pair-direction (`prompts/verify-matrix.md`): every sampled excerpt judged against L0/L1/L2 independently (instantiates | contradicts | insufficient); verbatim quotes required for decided verdicts at L1/L2, machine-validated against the masked excerpt text (failed quote → that verdict downgraded to insufficient, logged); L0 quote-exempt. Judges: a2b (D_A vs E_B) = opus; b2a (D_B vs E_A) = codex terra (each side's excerpts judged by the family that did not write them). Per-level aggregation, per direction: k/c/u counts; abstain iff k+c < 2; covers iff k ≥ 2 ∧ c = 0; fails iff c ≥ 2 ∨ k/(k+c) ≤ 0.3; else mixed. **Coverage level L = max level whose aggregate is covers** (−1 if none). **Monotone** iff no level below L aggregates fails. **Direction identities (F3): La = the coverage level of direction a2b = D_A (community A's ladder) judged against E_B (community B's excerpts); Lb = direction b2a = D_B judged against E_A. T1 = community A's term, T2 = community B's term, everywhere (decompose, containment).** In the composition table, "the covering side" of an asymmetric row is the community whose ladder achieved level 2: (La=2, Lb≤0) → covering side = A → serialized broadnarrow(broader_side=a); (Lb=2, La≤0) → broadnarrow(broader_side=b).
8. **Symmetry check** (fires only per table row 3): the failing direction's L1 definition re-judged against the same excerpt sample by the OTHER family (b2a → opus; a2b → codex terra) with the single-definition template (`prompts/verify-pair.md`); **confirmation = fails with c ≥ 2 at L1** under the same aggregation.
9. **Decompose** (fires only in path P): isolated sonnet call (`prompts/decompose.md`, commitment-disciplined); output = specific shared core + one verbatim quote per side (machine-validated against masked samples) or the literal token ABSTAIN. **ABSTAIN is a valid semantic outcome**; unparseable/missing output or failed quote validation is an infrastructure failure per §4.
10. **Containment v2** (fires only after decompose success): isolated codex-terra call (`prompts/containment-v2.md`): neutral framing ("may or may not be related"), options **t1_within_t2 | t2_within_t1 | partial_overlap | no_relation | unclear**, each decided option requiring one verbatim quote per side, machine-validated; failed validation or unparseable → infrastructure failure per §4.

## 3. Verdict vocabulary

Hard relations (assertions): exactMatch · broadnarrow(broader_side) · relatedMatch · noMatch · noMatchDespiteSimilarity. Escalation (not a relation): **reviewRequired(reason)** — records serialization: proposed_relation = null, status = "review_required", reason field; it is never correct, and it is never a promotion. Terminal states: insufficientEvidence(reason) · configFail(reason).

## 4. Terminal conditions (checked in this order, before the composition table)

**configFail(reason), pair-scoped** (a pair fails if either of its terms is affected): polarity inversion (term-scoped); any artifact-gate exhaustion under the §1 state machine — checklist or ladder failing any gate after its one regeneration (term-scoped).
**insufficientEvidence(reason), pair-scoped — infrastructure failure at ANY per-pair stage (F2's totality demand; enumerated):** excerpt sample < 4 for either term; verification output for either direction missing, unparseable, or an API refusal; quote-validation collapse leaving < 2 decidable verdicts at every level in either direction; either direction non-monotone; both directions starved (k + c < 2 at every level); symmetry-check output missing/unparseable/refused WHEN the composition row requires it; decompose output missing/unparseable/refused or its quote validation failing WHEN path P requires decompose (semantic ABSTAIN is NOT a failure — it flows through path P); containment output missing/unparseable/refused or its quote validation failing WHEN path P requires containment.
**Run-scoped faults** (not verdicts): retrieval execution failure, harness/scorer crashes — fix the infrastructure and re-execute that stage; every such re-execution is logged.

## 5. Composition table (TOTAL over (La, Lb) after terminals; mirror rows implied; "deep-c" = c ≥ 2 at L1 in the direction's matrix)

| (La, Lb) | verdict |
|---|---|
| (2,2) | exactMatch |
| (2,1) | reviewRequired(detail-divergence) |
| (2,0) or (2,−1), deep-c in the failing direction ∧ symmetry confirms | broadnarrow(covering side) |
| (2,0) or (2,−1), deep-c ∧ symmetry does not confirm | reviewRequired(asymmetry-unconfirmed) |
| (2,0) or (2,−1), no deep-c (incl. c≥2 only at L2) | reviewRequired(unexplained-asymmetry) |
| (1,1) · (1,0) · (1,−1) · (0,0) · (0,−1) · (−1,−1) | path P |

**Path P**: mutual retrieval hit ∧ decompose success → containment v2 (T1 = A's term, T2 = B's term): t1_within_t2 → broadnarrow(broader_side=b) · t2_within_t1 → broadnarrow(broader_side=a) · partial_overlap → relatedMatch · no_relation → (surface-similarity flag ? noMatchDespiteSimilarity : noMatch) · unclear → reviewRequired(containment-unclear). Decompose ABSTAIN, or no mutual hit → (surface-similarity flag ? noMatchDespiteSimilarity : noMatch).

**Surface-similarity flag (exact; F5)**: normalize both term strings by lowercasing, folding curly quotes/dashes to ASCII, collapsing whitespace runs to single spaces, and trimming; flag fires iff (i) the normalized strings are equal, OR (ii) letting S(x) = the normalized string with every non-alphanumeric character removed and T(x) = the set of character 3-grams of S(x): T(term_a) is non-empty ∧ |T(a) ∩ T(b)| / |T(a) ∪ T(b)| ≥ 0.5. If S(x) is shorter than 3 characters for either term, only clause (i) can fire.

## 9. Round-2 review folds (spec-text; the executable package is built AFTER this document stabilizes)

- **Sampling pool (F3, amended at build — §0.11/finding B1):** the held-out encroachment rule of v0.2–v0.7 is REMOVED, and so is the split that made encroachment possible. The F3 kernel stands: sampling never silently crosses a declared boundary. The declared boundary is all 11 docs per side — v0.8 has no held-out instrument (E2 removed), so a 01–08 reservation would protect nothing while (measured at build, before any model call) leaving 7/10 pairs below the §4 floor on the frozen corpus (E1 ceiling 3/10, a foreknown-fail run). Fewer than 4 pool excerpts for a term → terminal insufficientEvidence for its pairs; the scorer asserts mechanically that every sampled excerpt's doc index is ≤ 11 and that the sample is the first-6 prefix of the pool in (doc, position) order.
- **Per-stage failure table (F4):** generation-stage call failures (checklist, ladder — missing/unparseable/refused output) CONSUME the artifact's single regeneration budget (the state machine IS the retry policy; §7's "no automatic retry" means no retries outside it); second failure → term-scoped configFail. Polarity batch missing/unparseable/refused → one re-run, then side-scoped configFail. Verification/symmetry/decompose/containment failures → pair-scoped insufficientEvidence per §4 (no retries). Conformance-judge batch failure → one re-run, then run-halt (it gates everything). The runner exits nonzero on any unresolved failure; downstream stages never run over unresolved upstream failures; output files from failed calls are deleted before any re-run (no stale-output reuse).
- **Mechanical validators (F5, F6):** w() = whitespace-token count; sentence count = segments produced by splitting on [.?!] followed by space+capital, after stripping the trailing terminator. Ladder mechanical gate enforces: L0 exactly 1 sentence AND w(L0) ≤ 45; L1 2–4 sentences; L2 60–160 words; w(L0)<w(L1)<w(L2). Checklist mechanical gate: 4–7 non-empty lines, each ≤ 40 words. Every model output is schema-validated: matrix output must contain exactly one row per sampled excerpt with unique excerpt ids 1..n and all three levels present with verdicts in the allowed enum — any violation (missing/duplicate/out-of-range rows, missing levels, unknown enum values) is classified "unparseable" and routed through §4. Same rule for polarity and symmetry batches (exact per-item coverage). Containment v2 schema: {"relation": one of the five enums, "quote_1", "quote_2", "justification"} with ALL FOUR keys present as strings — a missing key is malformed = unparseable (round-3 F3); quotes REQUIRED and machine-validated for t1_within_t2 / t2_within_t1 / partial_overlap / no_relation; "unclear" is quote-exempt (quote fields present, ignored). Conformance-batch schema (round-3 F4): exact per-item coverage; verdict ∈ {conformant, nonconformant}; reason a string and NONEMPTY for nonconformant — a bare nonconformant verdict is malformed and routes to the batch re-run (§9-F4), never to the artifact's regeneration budget. **Quote machine-validation, all stages (round-3 F1 disposition):** a quote validates iff it appears as a contiguous substring of the masked excerpt text the judge saw, compared after folding case, typographic quotes/dashes to ASCII, and collapsing whitespace runs — the matcher carried unchanged from v0.2–v0.7. The folding admits no word-level alteration (every word, in order, must appear), so fabricated or edited evidence still fails; strict raw comparison was considered and rejected because it adds false downgrades (→ starvation terminals) without excluding any fabrication class.
- **Retrieval determinism (F7):** the encoder is loaded from an explicit local snapshot path recorded in the freeze; ranking = sort by (−similarity, document_index); snapshot hash = sha256 over the sorted list of (relative path, file sha256) pairs.
- **Runtime provenance honesty (F9):** provider-side alias resolution is NOT observable at this channel and is NOT claimed to be recorded; the archived manifests record the requested alias + invocation environment. The isolation wrapper's `model_reasoning_effort=high` for codex calls is part of the frozen configuration (not a CLI default) and is declared as such.
- **PROTOCOL alignment (F8):** PROTOCOL.md is amended and hashed in the freeze: the TEST-firing bar is v0.8's E1 primary in full (correct ≥7/10 ∧ promotions = 0 ∧ jingle-specific ≥ 1 ∧ false escalations ≤ 1), with reviewRequired defined as an escalation that is never a promotion.
