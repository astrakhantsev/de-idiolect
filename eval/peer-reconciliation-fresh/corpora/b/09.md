# Integrated Contamination Audit

The final audit used 1,200 paired operational tasks generated under a subordinate authoring protocol. The subordinate authoring protocol supplied executable validators while withholding task-generation traces from every evaluated system. Each task family included matched contrast probes with identical required actions and variable irrelevant context.

Matched contrast probes increased excess tool usage by 26% for the largest agent. A salt run was inserted into every 100-item block, and salt run failures halted scoring before the affected block entered the aggregate analysis. The item discrimination exhaustion rate was monitored separately for clean and distractor-loaded variants. The item discrimination exhaustion rate was higher for clean variants, where most strong agents succeeded uniformly.

Reflexive adjudication used anonymized final outputs from both variants. Reflexive adjudication produced a 5.1-point self-output agreement deficit, concentrated among outputs with unusually confident rationales. The echo test found inappropriate copied example phrasing in 6.8% of those rationales. After example paraphrasing, the echo test rate fell to 1.5% without materially changing matched contrast probes or reflexive adjudication.
