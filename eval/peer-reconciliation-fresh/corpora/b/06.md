# Capability-Calibrated Retention

The evaluation suite contained 3,050 tasks spanning three capability tiers and two execution environments. Every item received a tier floor annotation before model results were inspected. The tier floor annotation was revised for 4.7% of items after annotators discovered hidden dependencies on unavailable credentials.

The item discrimination exhaustion rate was computed separately within each tier. The item discrimination exhaustion rate reached 0.46 for entry-tier tasks but remained below 0.20 for the highest tier, indicating that maintenance pressure was concentrated in simple retrieval and formatting tasks. Removing exhausted items increased rank stability across weekly reruns.

Failures below an agent’s tier floor annotation were flagged for audit rather than treated as ordinary misses. The tier floor annotation also exposed a limitation: several agents completed higher-tier items through narrow memorized procedures while failing lower-tier tasks requiring unfamiliar tool states. Consequently, the reported exhaustion analysis does not imply a single monotonic capability scale.
