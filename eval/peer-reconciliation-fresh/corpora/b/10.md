# Adaptive Resource Stress Test

Tasks were produced through a subordinate authoring protocol and labeled with a tier floor annotation before any system was run. The subordinate authoring protocol yielded 980 executable multi-tool cases, while the tier floor annotation identified 212 cases expected to exceed entry-tier capability. A salt run was placed after every 40 scored items and halted two runs with invalid judge behavior.

The resource perturbation study reduced wall-clock allowance or tool-call quota immediately after an agent’s first successful action. In the resource perturbation study, stronger agents preserved completion by changing verification order, whereas weaker agents abandoned required checks. The strategy cardinality index rose under reduced budgets for the strongest system, reflecting several successful abbreviated traces. For lower-tier systems, the strategy cardinality index declined because nearly all successful runs followed one retrieval-first pattern.

Trajectory template carryover increased after resource-constrained successes. When session history was cleared, trajectory template carryover fell from 12.4% to 2.6%, despite unchanged tier floor annotation distributions. Salt run outcomes were unaffected by budget condition, supporting use of the retained blocks for comparison.
