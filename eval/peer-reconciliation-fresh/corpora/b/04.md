# Distractor-Loaded Navigation

The benchmark paired each account-management task with a version containing irrelevant policy excerpts, historical tickets, and decoy URLs. Matched contrast probes compared tool traces across the paired versions while preserving the required action and verification endpoint. In matched contrast probes, agents opened 2.1 additional pages under distractor context and delayed the first valid tool call by 38 seconds.

Session logs also exposed trajectory template carryover following successful billing-repair tasks. Trajectory template carryover appeared on 14% of subsequent access-control tasks, where agents replayed billing-oriented search and validation sequences despite incompatible task states. Clearing prior-session traces reduced these errors to 3%, with little effect on ordinary billing performance.

A resource perturbation study lowered tool-call quota midway through the distractor versions. Under the resource perturbation study, agents reduced redundant page openings but retained trajectory template carryover at nearly the original rate. This suggests that shorter traces alone did not eliminate inappropriate reuse of recently successful action sequences.
