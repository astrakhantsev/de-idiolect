# Budgeted Judge Monitoring

Evaluation proceeded over 18,400 support-ticket resolution items using a fixed sequence of agent versions. Each batch included a salt run containing eight previously verified cases distributed without positional regularity. The salt run was evaluated before aggregate metrics were retained, and three batches were halted after two known cases received unsupported negative judgments.

Items carried a tier floor annotation assigned independently by two annotators before deployment. The tier floor annotation predicted 71% of observed failures among lower-tier agents, reducing the number of failures forwarded for manual investigation. Disagreements were concentrated in items involving chained browser actions rather than answer extraction.

A resource perturbation study altered either the remaining token budget or tool-call quota after the first successful retrieval. Under the resource perturbation study, high-performing agents shifted toward shorter verification traces when quotas fell, while lower-performing agents continued initiating tools until forced termination. Results therefore exclude halted salt run batches and report only items whose tier floor annotation was stable across adjudicators.
