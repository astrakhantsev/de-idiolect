# Session-State Ablation

Agents were evaluated in 24-task sessions arranged to alternate configuration, billing, and incident-response work. A salt run was inserted twice per session, using verified items whose answers were absent from the session briefing. The salt run halted six sessions after judges accepted an incorrect configuration change as compliant.

The same sessions were examined for trajectory template carryover after high-confidence successes. Trajectory template carryover was most frequent when an incident-response task immediately followed a successful billing recovery, producing repeated credential-reset actions on unrelated systems. Resetting session history between items reduced this pattern by 79%, although it modestly increased tool setup time.

The salt run halt rule prevented contaminated sessions from contributing to carryover estimates. After removing halted sessions, trajectory template carryover remained associated with prior trace length rather than prior answer correctness. The analysis is limited by the fixed task ordering; a fully randomized schedule may yield a smaller effect.
