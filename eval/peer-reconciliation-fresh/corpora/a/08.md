# Four things went sideways in one afternoon

Rough afternoon of eval debugging. Started with a dead weight census sanity check on our onboarding-flow suite — 44% pass-everything or fail-everything, worse than last quarter, and I think it's because two agent generations back we plateaued on the exact skill this suite tests, so nothing separates anymore.

Then tried a squeeze play on the same suite's harder half, halving budget right at the point the agent starts drafting its final response. Two of three agents compressed cleanly, the third just truncated mid-sentence and got scored as a failure, which feels like the right outcome even though it stung to watch.

Ran an echo test afterward because the third agent's truncated output looked suspiciously different from a supposedly identical earlier run with no squeeze play involved. Turned out to be real — same prompt, same session, two different truncation points, so there's stack-level nondeterminism layered on top of the budget-cut behavior, and now I can't cleanly separate the squeeze play effect from ordinary echo test noise without a lot more samples.

Capped the day off by setting a reread ration on the onboarding suite for the first time, since half of what's inflating the pass-everything bucket in that census looks like agents brute-forcing through repeated file opens instead of actually reasoning. Ration of three, rerunning tomorrow, expecting the pass-everything number to finally move.
