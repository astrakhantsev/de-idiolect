# Budget cut mid-task, twins mismatched, and the agent grading its own homework

Ran a squeeze play on Palisade agent's contract-review flow yesterday. Silently cut its remaining token budget in half right after it finished reading the contract but before drafting the summary. It noticed around the point where its own running estimate crossed 50%, dropped the bullet-heavy style it'd been using, and finished in six terse sentences instead of the usual seventeen. Genuinely impressive, first agent on our roster to pass that cleanly.

Less happy about our twin runs results this week. Same underlying task, one variant phrased as a casual Slack message ("hey can you check this contract real quick"), the other as a formal request with numbered requirements. Twelve point pass-rate gap between the twins, all attributable to wording since the actual task content was byte-identical otherwise. That's a bigger presentation tax than I want to admit to leadership.

And on ouroboros items — we had Palisade draft forty candidate eval questions about contract clauses, then used a second model to strip out the ones it thought Palisade would find trivial. Kept eighteen. Went back and checked: fourteen of the eighteen are still clause-parsing questions, which happens to be exactly what Palisade is best at. The filter model didn't catch the skew because it shares the same blind spot. Need a third, genuinely different model in that loop.
