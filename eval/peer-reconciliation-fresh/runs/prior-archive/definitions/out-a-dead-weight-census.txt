⟦TERM⟧ is a diagnostic procedure run on a fixed evaluation suite of a set number of items to measure how well that suite still separates different versions of a fielded agent. You take the suite, run every item across two or more (usually several) agent versions, and tag each item as "pass-everything" (passed by all versions) or "fail-everything" (failed by all versions). The result is the percentage or count of such items out of the total suite size — the fraction that shows no difference across versions. A higher percentage means the suite discriminates less between versions, because those items no longer distinguish one version's capability from another's. It applies when comparing multiple existing agent versions against one stable suite.
