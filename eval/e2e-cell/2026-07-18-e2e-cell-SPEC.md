# End-to-end cell on C2 — SPEC rev 2

## 0. Prior-run inventory (unchanged from rev 1)

Already run, not redone: memorization screen (bare coinage L0 on 8/8 configs); weights-only definition-mediated naming (C2 = the one clean cell); definition-as-key retrieval on eggs (oracle-supplied concepts); cross-community curated-pair cell (killed; thresholds at chance). **This cell adds:** candidate-term surfacing wired in (retrospective demo), answer-blind definition *regeneration* under the sealed rule with a **fidelity gate**, retrieval from a **real-document** corpus on a real coinage, and one **equal-information frontier baseline**. Relation typing is **out of scope** (rev-1 F7): it needs concept pairs and frozen gold labels — a separate study; the component table keeps "not measured."

## 1. Question and claim ceiling

Starting from the project's frozen C2 excerpts, does an answer-blind constrained definition route to the **decision-analytic question family — literature on when information of a given quality is worth acquiring or acting on** — in a mixed real-document corpus, better than the coinage itself as a query? **Claim ceiling (rev-1 F1): routing to the relevant question family.** Not "recovery of the owner of the project's quantitative result" (the 07-16 record is explicit that Raiffa–Schlaifer owns the question *type*, not the project's RMSE schedule), and not a study — an exploratory one-case demo, promoted no further regardless of ranks.

## 2. Stages and materials

1. **Candidate-term surfacing — retrospective detection demo** (rev-1 F9: the vault is not version-controlled, so pre-discovery file contents cannot be attested; this is a *retrospective* demo, labeled as such). Frozen at build time in `detect.py`: exact file manifest with sha256 hashes (`flf/` files with filename dates ≤ 2026-07-12), background corpus = `30_reference/` manifest, scikit-learn `TfidfVectorizer` with `ngram_range=(1,3)`, `lowercase=True`, default tokenizer, English stopwords, sublinear TF; per-document aggregation = max; ranking = descending score, ties broken lexicographically. **Endpoint: the exact string "operating requirement" appears in the top-25 n-grams.** Reported either way.
2. **Frozen concept excerpts.** `def-naming-raw/excerpts-frozen.md` C2 section verbatim (unchanged).
3. **Fidelity checklist — frozen BEFORE generation** (rev-1 F3). From the C2 excerpts, the definition must preserve: (i) the decision is whether an instrument/signal is worth building or acquiring; (ii) it is conditioned on a stated quality/accuracy level; (iii) it is prospective — decided *before* building; (iv) it has threshold structure (act if quality clears a bar); (v) it must not add benchmark or metric specifics absent from the excerpts. An answer-blind judge (isolated per §5-G3, sees only excerpts + definition) marks each item preserved / contradicted / unsupported-addition. **Any load-bearing failure (i–iv contradicted, or v violated) fails that generator config. No regeneration on fidelity grounds** — fidelity failure is a result, not a retry trigger.
4. **Answer-blind definition generation (regeneration on leaks only).** Generator (isolated per §5-G3) gets frozen excerpts + the constrained-definition instruction. Leak check per §5-G2; any hit → full regeneration (new sample), max 3 attempts; 3 leaking attempts → that config FAILS LOUDLY. k = 2 configs (sonnet, opus), one accepted definition each. **A missing/failed D config = primary-endpoint failure** (rev-1 F10), not a silent narrowing.
5. **N — naive-question arm, frozen procedure** (rev-1 F5): exactly one N query, generated by the sonnet config under the same isolation, from the same excerpts, instruction: "restate the practical question these notes are asking, in one plain-English sentence a non-specialist would type into a search engine." Leak-checked like D (both term classes). N's role is fixed in §4.
6. **Corpus — 18 real documents, frozen before D/N generation** (rev-1 F2). Title + abstract records of real published items, each with source ID (DOI/arXiv/PubMed/stable URL) and sha256 of the stored record; relevance label + one-sentence rationale per document, all frozen before any query generation. Composition and rule-bound selection (curator is answer-aware; mitigation = fixed queries, take-first-k relevant results in source order, no re-rolls, exclusions logged):
   - **Owner set, M = 3** — frozen queries: "expected value of sample information" (PubMed); "value of information analysis decision" (Semantic Scholar); "diagnostic accuracy threshold target product profile" (PubMed). Label rationale: addresses when information of a given quality is worth acquiring/acting on.
   - **Misroute set, 6** — 2 each from the fields the coinage empirically misroutes to: audit sampling/attestation standards; recommender cold-start; MCMC burn-in/convergence diagnostics.
   - **Distractor set, 9** — one each, frozen topics: conformal prediction; topic models; instrumental-variable estimation; curriculum learning; spectral clustering; survival analysis; data augmentation; graph neural networks; active learning. *(Active learning is deliberately included as a hard near-neighbour; its label is distractor with rationale logged — it optimizes acquisition of labels, not the worth-of-an-instrument decision.)*
7. **Retrieval.** `bge-large-en-v1.5`, cosine, offline, deterministic. Queries: K1, K2, N, D-sonnet, D-opus (§3). Metrics: rank of first owner doc; **hits@5** (count of owner docs in top 5 — named per rev-1 F6).
8. **Equal-information frontier baseline — ONE config** (rev-1 F10/F11): GPT-5.6 via codex (isolated per §5-G3), receives the frozen excerpts + all 18 records (shuffled, labels stripped) and returns the 5 records most likely to be the established literature on the excerpts' question, ranked. **F✓ is defined as: ≥1 owner doc at rank ≤2 of F's list.** Scored with the same metrics.

## 3. Arms

**K1** `operating requirement` · **K2** `the cold-start operating requirement for the audit unit` (the in-project phrase; both controls per entry-review F3) · **N** per §2.5 · **D-sonnet, D-opus** per §2.4 · **F** per §2.8.

## 4. Pre-registered endpoints — exact, chance-benchmarked (not "chance-adjusted"; rev-1 F6)

Frozen counts: N_docs = 18, M = 3. Under uniform random ranking: P(first owner at rank 1) = 3/18 ≈ **0.167**; P(first owner ≤ 2) = 1 − (C(15,2)/C(18,2)) = 1 − 105/153 ≈ **0.314**; expected hits@5 = 5·3/18 ≈ **0.83**. These numbers are printed next to every reported rank.

- **Primary (delivered value, comparative):** for BOTH D configs: first owner doc at **rank 1**, AND strictly better first-owner rank than K1 and K2. A failed D config = primary failure.
- **Mechanism interpretation (rev-1 F5, binding):** D vs N. If N ties or beats D on first-owner rank for either config, the result is reported as an **elaboration effect** (a specific question beats an opaque phrase) and **no definition-specific claim is made** — this repeats and extends the prior backtest's suggestion, honestly labeled.
- **Baseline comparison (reported, not gated):** F per its frozen success definition. Quadrants: D✓F✓ → pipeline routes; frontier-with-corpus also routes; marginal-value framing stands. D✓F✗ → strongest outcome. D✗F✓ → null for the pipeline's mechanical form; entry reports it. D✗F✗ → construction failure; no claim.
- **Detection endpoint:** §2.1, reported either way, labeled retrospective.
- Nothing outside this section is claimed; anything else observed is labeled exploratory commentary.

The unlisted-name hole is closed by **fidelity item (vi): any named field, discipline, method, author, or acronym in the definition that is absent from the excerpts = config FAIL** — not merely disclosed.
5. **Auth under isolation →** isolated homes contain ONLY the CLI credential file (`~/.claude/.credentials.json` / `~/.codex/auth.json`) — no settings, memory, or config; `run_isolated.sh` gains `preflight-claude` / `preflight-codex` modes that must succeed (and probe-report NONE) before any real run; home contents listed in each manifest.

7. **Detection formula →** score = max tf-idf over PROJECT docs only, among n-grams with background df = 0; markdown ingested as raw text; sklearn version logged in `detection.json`; **the script sha256 is the frozen config**.
8. **Budget →** post-freeze execution capped at ~95–110 min: corpus finalize 10 · preflights + prompts 15 · D/N/fidelity runs 20 · retrieval 10 · F 10 · write-up 30; **entry folding is OUTSIDE the cell budget** (contingent on the user's submission decision, per rev-1 F11).
