A named accuracy threshold for a numerical estimate, expressed as a maximum tolerable error size, below which the estimate is worth using instead of skipped. It applies to any situation where someone computes a single number meant to stand in for a count or multiplier that will feed into a downstream judgment, and where the person could instead simply not compute that number at all. The threshold is set on the typical size of the gap between the estimate and the truth, measured on a scale where errors above and below the true value count symmetrically. Below one level of this gap the estimate keeps nearly all of its potential benefit; around a middle level it keeps about half; past a further level the estimate stops helping and instead actively misleads, because a badly wrong number creates false confidence worse than having no number at all. Any specific estimating procedure can be checked against this threshold by measuring its typical error and comparing that figure to the named levels.
