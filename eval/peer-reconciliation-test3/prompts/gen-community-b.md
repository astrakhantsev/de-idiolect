"cross-lingual instruction fidelity" — Task instructions are presented in a language other than the one the surrounding harness scaffolding is written in, with task difficulty and constraint count held constant. Adherence to each stated constraint is scored to detect whether an agent silently relaxes its constraint-following when a request arrives outside its dominant language.
2. "cold start" — The wall-clock delay between an evaluation being launched and the agent issuing its first executable action is measured, isolating time spent provisioning the sandbox, mounting the repository, and loading the harness from the agent's own deliberation time. Reported as fixed overhead per run so that throughput figures can be corrected for infrastructure cost.
3. "goal-revision compliance rate" — Partway through execution a scripted user message reverses an earlier instruction; graders record whether the agent discards the now-invalid partial work and pursues the revised objective, versus finishing the stale one. Scored as the fraction of trials in which the agent fully switches without carrying abandoned artifacts into its final output. Applies to multi-turn interactive runs where instructions can change mid-task.
4. "post-completion action count" — One specific case inside the general question of whether an agent halts at the right moment: an automated checker confirms the objective is already fully satisfied, and from that instant every further tool invocation the agent issues before terminating is tallied. It captures only overruns past a solved state, ignoring stopping too early or looping without progress, which the wider question also covers.

Each single-ingredient ablation is one case contained within this general quantification.
6. "hot swap" — Freshly authored problems are quietly substituted for a portion of a standing benchmark's items between evaluation cycles, with difficulty held comparable. Any sudden score drop on the substituted slots relative to the untouched slots is treated as evidence that the retired problems had been absorbed during training rather than genuinely solved.
7. "corrupted-observation recovery index" — A recorded run is executed again while every tool result is replaced with syntactically valid but semantically meaningless content. Observers track whether the agent flags the unusable feedback and requests a retry rather than proceeding as though the output were sound. Reported as the proportion of degraded steps that trigger an explicit recovery attempt. Used when assessing how a testing rig behaves under faulty observation channels.
8. "grader temporal stability coefficient" — One agent answer is submitted to the automated scorer at two well-separated times with the scorer's own sampling randomness left unconstrained and its input held byte-identical. 9. "reference trajectory alignment score" — An agent's ordered sequence of actions is aligned against a hand-curated ideal sequence for the same task using an edit-distance procedure over action types and arguments. The normalized similarity is reported to indicate how closely the route taken tracks the intended one, computed independently of whether the final answer was correct.
10. "component substitution elasticity" — A task is repeated with the module that decides which tool to invoke reassigned to a different model while the remainder of the stack is held fixed. The change in how many total actions the run consumes is measured to characterize that module's contribution to efficiency.
