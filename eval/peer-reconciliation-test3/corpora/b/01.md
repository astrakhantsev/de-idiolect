# Launch and Language Conditions

The Atlas-12 suite paired repository repair tasks with harnesses written in English, while task instructions were supplied in Spanish, Korean, or Arabic. Constraint count, file scope, and expected patch size were matched to English-instruction controls. Cross-lingual instruction fidelity was evaluated at the individual-constraint level across 480 trials. Cross-lingual instruction fidelity declined by 8.6 percentage points for the smallest model, concentrated in requirements concerning test execution and preservation of unrelated files.

Run timestamps were instrumented before repository mounting and after the first shell or editing action. Cold start accounted for a median 41.2 s per trial on the shared-worker configuration. Cold start remained stable across instruction languages, indicating that the observed language effect was not attributable to provisioning variance. After subtracting cold start, the large model’s median deliberation-and-execution interval differed by less than 3% between language conditions.

Failure review found that agents usually completed the requested code change but omitted a secondary formatting or validation constraint. The limitation is that translated instructions retained the same task semantics; these results do not establish behavior under culturally localized or deliberately ambiguous requests.
