# Combined Robustness Sweep

The combined sweep evaluated translated repository tasks with a solved demonstration removed and an instruction reversal inserted after initial inspection. Cross-lingual instruction fidelity was calculated before and after the reversal to preserve all constraints from both user messages. Cross-lingual instruction fidelity decreased by 11 points in the no-demonstration condition, with the largest loss on commands requiring a final test report.

Cold start was logged for every run and subtracted from time-to-revision analyses. Cold start contributed 37 s at the median and did not differ across ablation cells. Goal-revision compliance rate was 0.73 after adjustment for task length. Goal-revision compliance rate was 0.16 lower when the reversal arrived in a non-English instruction than in the English control.

Post-completion action count was tallied from the checker-confirmed completion point for the revised objective. Post-completion action count doubled when agents preserved obsolete exploratory files. Prompt scaffolding dependence measure was estimated across each removed support ingredient. Prompt scaffolding dependence measure was greatest for demonstration removal, rather than for loss of formatting cues.

Hot swap supplied newly authored items to half of the final evaluation block. Hot swap produced an additional 6-point completion decline, but confidence intervals overlapped those from the language condition. The factorial design was not powered to identify interactions among all six factors.
