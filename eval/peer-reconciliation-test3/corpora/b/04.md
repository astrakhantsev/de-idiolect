# Faulty Tool Feedback and Score Repeats

Recorded browser and shell interactions were replayed with syntactically valid tool outputs whose contents no longer corresponded to the requested operations. Corrupted-observation recovery index was computed at every degraded observation boundary. Corrupted-observation recovery index was 0.68 for the deliberative agent and 0.31 for the action-heavy agent. Explicit retry requests were common after malformed-looking directory listings, but much rarer after plausible yet irrelevant test output.

The same completed answers were then submitted to the scorer on four dates separated by at least 21 days. Grader temporal stability coefficient was estimated from the resulting numeric-score pairs across 600 answers. Grader temporal stability coefficient was 0.93 for repository-state tasks and 0.71 for open-ended incident reports. Lower stability coincided with borderline partial-credit judgments rather than with answer length.

The replay protocol intentionally preserved command syntax and response shape, which isolates semantic unreliability but does not represent connection failures or visible tool errors. Scorer sampling was left unconstrained, so part of the temporal variation may reflect ordinary stochasticity rather than persistent changes in grading behavior.
