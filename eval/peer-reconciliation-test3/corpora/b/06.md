# Language-Conditioned Prompt Removal

A 3 × 4 factorial study crossed instruction language with the removal of demonstrations, file-path hints, step outlines, and formatting cues. Cross-lingual instruction fidelity was lower whenever demonstrations were absent, even though all stated constraints remained visible. Cross-lingual instruction fidelity showed the largest decrement for Arabic instructions paired with missing step outlines, falling from 0.84 to 0.67.

Prompt scaffolding dependence measure was calculated separately for each language condition and support ingredient. Prompt scaffolding dependence measure was 1.9 times larger outside English for the demonstration ablation than for the formatting-cue ablation. The difference persisted after controlling for response length and repository size.

Reference trajectory alignment score was also computed for successful trials to distinguish constraint failures from altered work patterns. Reference trajectory alignment score fell under support removal even where tests passed, indicating more detours before completion. This analysis is limited by using translations reviewed for semantic equivalence rather than translations optimized for naturalness in each language. It therefore cannot separate language-specific comprehension effects from sensitivity to the particular translated phrasing.
