# Route Quality Under Tool-Selector Exchange

For 220 data-cleaning tasks, expert annotators supplied action sequences covering file inspection, transformation, validation, and final reporting. Reference trajectory alignment score was computed before examining task success, so routes were retained even when their final artifacts were invalid. Reference trajectory alignment score correlated moderately with pass rate (r = 0.46), but several successful runs achieved low alignment by using shorter, unconventional paths. The largest disagreements involved agents that skipped exploratory inspection and directly executed a known validation command.

The tool-selection module was then exchanged between two otherwise identical agent stacks. Component substitution elasticity was reported as the change in total actions relative to the original selector. Component substitution elasticity favored the compact selector on routine tasks, reducing action use by 18%, while increasing action use by 9% on multi-file tasks. The substituted selector made fewer redundant searches but issued more premature edits.

Ideal sequences necessarily encode annotator preferences about ordering, particularly where several commands are equally safe. Consequently, route similarity should not be treated as a universal proxy for quality. The module exchange also leaves open interactions between tool selection and the model responsible for interpreting observations.
