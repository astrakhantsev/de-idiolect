# End-State Behavior Across Evaluation Cycles

The final study combined support ablation, refreshed tasks, faulty observations, and scorer repeats in a single 1,200-run panel. Post-completion action count was calculated only after an independent checker confirmed the requested revision, tests, and report were complete. Post-completion action count averaged 3.4 under intact prompts and 5.6 when misleading observations preceded completion.

Prompt scaffolding dependence measure was estimated for each supportive ingredient while preserving the same task instances. Prompt scaffolding dependence measure was largest for removed demonstrations, particularly on multi-file repair tasks. Hot swap replaced one quarter of items in the last cycle with matched new problems. Hot swap lowered success by 9.8 points and increased the gap between intact and ablated prompts.

Corrupted-observation recovery index was derived from the degraded-observation portions of the panel. Corrupted-observation recovery index rose when agents had retained an explicit validation step in their prompt. Grader temporal stability coefficient was computed over four scorer submissions per answer. Grader temporal stability coefficient exceeded 0.90 for executable-task outcomes but was lower for explanatory summaries.

Reference trajectory alignment score was assessed independently of final success for all completed runs. Reference trajectory alignment score declined after hot-swapped items, even among passing trajectories. Component substitution elasticity was estimated by exchanging the tool-selection module within matched task pairs. Component substitution elasticity reduced action use in familiar tasks but increased it after corrupted observations. These results remain limited by a fixed set of repositories and a single automated checker configuration.
