# Five things that broke our eval pipeline this month

Rough month. Started with a brain swap experiment gone sideways — routed planning through a cheaper model while keeping execution untouched, expecting a moderate dip, and instead task success collapsed from 79% to 31%. Turned out our executor was far more dependent on detailed subplans than we assumed, it basically can't improvise. Good data, bad surprise.

Then cold start bit us during the same experiment cycle. We hadn't controlled for it, so some of the brain swap sessions were accidentally comparing a fresh-session first task against a warmed-up session's later task, which inflated the apparent gap. Redid it controlling for position in session and the real brain swap effect was still large, just not as extreme as our first pass suggested.

Third, we caught a grader problem via double mark — resubmitted 200 answers with reflowed formatting only, and 14 flipped, concentrated almost entirely in the brain-swapped low-score batch, which makes sense since terser cheap-model output apparently trips something in the scorer's whitespace handling.

Fourth, unrelated fire: a hot swap forced on us by an API deprecation mid-batch, and about a third of in-flight sessions lost thread coherence, restarting work that was already done in files already edited.

Fifth, we finally ran a proper spray test on the shared execution cluster and found 11% cross-contamination between worker instances writing to a common cache directory, which we now suspect explains some of the weirder outliers from earlier in the month that we'd previously written off as model noise.
