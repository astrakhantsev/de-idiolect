A stated ceiling on how wrong a count-style estimate may typically be while still being worth producing at all. The decision it supports is made before any estimating tool is built: given only an assumed or simulated error level for the would-be tool, one asks whether a tool that accurate would beat simply using a fixed default number — in effect a Neyman–Pearson style acceptance test applied to the tool itself, as treated in the classical signal detection literature. If the assumed error stays under the ceiling the tool is worth building; past the ceiling it is not, because an estimate that wrong misleads more than having no estimate at all.
