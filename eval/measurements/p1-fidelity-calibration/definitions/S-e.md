A stated ceiling on how wrong a count-style estimate may typically be while still being worth producing at all. The decision is made before any estimating tool is built: given an assumed or simulated error level, one asks whether a tool that accurate would beat a fixed default number; in the standard evaluation this is operationalized as a typical percentage error below 15 percent, measured on a held-out benchmark set of ten thousand labeled cases. If the assumed error stays under the ceiling the tool is worth building; past the ceiling it is not, because an estimate that wrong misleads more than having no estimate at all.
