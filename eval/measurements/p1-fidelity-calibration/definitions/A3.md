Let a proposed tool output an estimate x̂ of an unknown quantity x, and let e denote the typical size of the gap between x̂ and x on a scale where over- and under-shoots count symmetrically. The concept is a fixed bar t on e, set before the tool exists: the choice to build the tool is made by comparing an assumed or simulated value of e against t, the fallback being a fixed default value d used in place of any estimate. It asserts a graded schedule g(e): for e well under t, g(e) is close to the full attainable benefit; for e near a middle value, g(e) is about half; and there is a break-even point e† past which g(e) turns negative, meaning a tool with error beyond e† leaves the user worse off than using d. Build only if the assumed e clears the bar.
