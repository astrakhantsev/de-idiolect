A go/no-go check applied to a tool that has not yet been built. Input: a stated typical-error level for the would-be tool, taken from an assumption or from a simulation that corrupts the true quantity with errors of that size; and the standing alternative, a fixed default number requiring no tool. Output: a verdict on whether building the tool is justified. Procedure: compare the stated error level to a fixed bar; under the bar, the tool would keep most of the benefit a fully accurate tool would deliver, so build it; near a middle level it keeps about half, which may still justify building; past the bar the projected estimates would mislead more than help — worse than the default — so do not build. The check exists so the build decision can be made from an error level alone, before any tool produces a real estimate.
