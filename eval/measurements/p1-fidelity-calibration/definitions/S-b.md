A way of scoring how much benefit a proposed estimating tool would deliver at a given accuracy, used before the tool is built. Given an assumed or simulated typical-error level for the would-be tool, one projects the benefit of building it relative to using a fixed default number. The projected benefit varies smoothly and gradually with the error level — a little more accuracy always yields a little more benefit, and a little less accuracy a little less — so there is no particular error level at which the verdict changes; the concept simply maps each error level to a degree of usefulness, and the builder weighs that degree against other considerations.
