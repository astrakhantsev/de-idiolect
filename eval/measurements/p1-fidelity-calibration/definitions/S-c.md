A stated bar on typical error that settles, before any tool is built, whether building an estimating tool is justified, with a fixed default number as the alternative. Given an assumed or simulated error level for the would-be tool, the rule is: build the tool only when its typical error exceeds the bar, since large errors are where an estimate adds the most; when the expected error is small — under the bar — the tool would add nothing over the default and building it is wasted effort. Benefit is graded accordingly: the largest gains come at the largest error levels, roughly half the gain at a middle level, and essentially none when error is smallest.
