## EXPERIMENT-LOG.md — protocol detail behind §5

- **E1 (§5.1)** — eggs routing check: for 3 oracle-supplied concepts (15-document corpus, offline, deterministic), the constrained definition puts the owning sub-field's document at rank 1, matching the raw term and beating the naive question (rank 4–8). Isolated effect is *specificity, not vocabulary-neutrality* — companion ablation **E1a is inconclusive** (both arms saturate at rank 1; on the one metric with headroom, the free-text arm led). *measured*, n = 3 concepts, one case, one model.
- **E2 (§5.2)** — curated-vocabulary cell, **pre-registered negative**: the first cell triggered its success rule at a threshold later shown to sit at chance, and claims built on it were retracted; a systematic second-cell search found no valid test pair — curated synonyms are memorized by construction, *measured on the vocabularies, models, and cutoffs searched; generalization is an argument*; candidate clean regimes narrow to post-cutoff concepts and private coinages. *measured* (with that scope).
- **E3 (§5.3)** — end-to-end cell, **pre-registered negative, with baseline**: both answer-blind constrained definitions failed the frozen round-trip fidelity gate on the same feature before retrieval could be scored — fidelity, not leakage, is where generation first failed its contract. Separately (outside the pre-registration), the retrospective detection demo missed its endpoint (coinage ranked ~224th). A grounded direct-model baseline given the same excerpts and corpus ranked the true owner literature 1–2, so the pipeline's mechanical form earned **no measured margin on this cell**. *measured*.
- **E4 (§5.4)** — follow-up measurement set on the same cell, graded per subresult: gate calibration **[pre-registered]** (four faithful definitions all pass, 0/4 false positives; five seeded single-defect definitions all fail on the planted item, detection 5/5, attribution 5/5 — bounded to author-constructed materials) — *measured*; a checklist-guided fix **[pre-registered]** clears the gate 2/2 versus 0/2 unguided — *measured* (**consistency, not a causal claim**: n = 1 per config, no contemporaneous unguided replicate); fidelity bought no routing (the two gate-passing definitions rank the first owner 2 and 3, no better than the drifted definitions they replace) — *measured (exploratory)*; union-of-keys **[pre-registered] null** (no fusion of keys weakly dominated the best single key; every fusion promoted the corpus's misroute document) — *measured*.
