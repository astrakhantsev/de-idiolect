# Collider-demo corpus manifest

The four documents the demonstration runs over: the two core CERN LHC-safety documents and two critique-side papers. **Full texts are not committed** (copyright boundary — see [`../README.md`](../README.md)). Committed instead: this manifest, [`fetch.sh`](fetch.sh) + [`clean_section.py`](clean_section.py) + [`build_sides.sh`](build_sides.sh) (which reproduce the local working corpus), [`sides.md`](sides.md) (the section→side map), and — under each component's directory — the tools' own paragraph-level excerpt receipts.

Identity was verified against the arXiv abstract page for each paper before use; two identity corrections were caught this way and are recorded below (they are the kind of provenance defect the entry's cite-time check exists to catch, §4.2). **`sha256` is of the extracted-text file as consumed on the fetch date** — a snapshot, not a canonical hash: text extraction is tool-dependent (defuddle / pandoc / pdftotext / the Jina reader all differ), so re-running `fetch.sh` with different tool versions may differ byte-for-byte. The stable identity is the arXiv ID + version. **License:** none of the four arXiv abstract pages surfaced an explicit license line through the extractor (defuddle strips the arXiv page footer); the arXiv default non-exclusive distribution license is assumed, and we do not redistribute the full texts — only paragraph-level excerpts for analysis and metadata.

## Identity corrections caught at fetch (reviewer-grade discipline, §4.2)

- **#1 LSAG authorship.** The kickoff prompt's expected author list ("G. Giddings, P. Heuer") was **wrong**: the LSAG report's authors are Ellis, Giudice, **Mangano**, Tkachev, Wiedemann. "Giddings" belongs to the *companion* accretion paper (#2, arXiv:0806.3381); there is no Heuer. Same-paper identity (title, arXiv ID, DOI 10.1088/0954-3899/35/11/115004, report number, abstract) confirmed. The expected metadata was the defect, not the fetched paper.
- **#2 Mangano's middle initial.** Recorded correctly as **M. L. Mangano** (Michelangelo L. Mangano, CERN), not the "M. M." a draft of the prompt carried.

Both are exactly the "real work, defective citation" failure mode the entry's §2 record documents and the cite-time check targets — surfaced here by verifying against the primary abstract page rather than trusting the brief.
